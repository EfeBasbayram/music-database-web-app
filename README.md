\# Music Database Web Application



A web-based music application developed using PHP and SQL. The system simulates a music streaming platform where users can explore artists, albums, songs, and manage playlists.



\## Features

\- User authentication (login system)

\- Artist, album, and song pages

\- Playlist creation and management

\- Music browsing system

\- Database-driven architecture

\- Data generation scripts



\## Technologies

\- PHP

\- MySQL / SQL

\- HTML

\- Basic Web Development



\## Database

\- Designed relational database schema

\- Includes SQL setup file

\- ER diagram included



\## How to Run

1\. Install XAMPP or any local server

2\. Place project in `htdocs`

3\. Import `database\_setup.sql` into MySQL

4\. Run project via localhost
